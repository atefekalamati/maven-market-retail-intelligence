# Raw data

Download the Maven Market dataset from Kaggle and place the original CSV files in this folder.

Expected files:

- `MavenMarket_Calendar.csv`
- `MavenMarket_Customers.csv`
- `MavenMarket_Products.csv`
- `MavenMarket_Regions.csv`
- `MavenMarket_Returns_1997-1998.csv`
- `MavenMarket_Stores.csv`
- `MavenMarket_Transactions_1997.csv`
- `MavenMarket_Transactions_1998.csv`

The raw files are excluded from Git because they can be downloaded again from the source. Do not rename or edit them before the data audit.
